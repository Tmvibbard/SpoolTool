1 · Takeoff

Drop the CSV

What this does: turns a Bluebeam Markups List export of trunk/feeder cable takeoffs into a reel order — how many reels of each cable to buy, which pulls go on which physical reel, and a numbered tag for every reel. For accurate results: give every run a real measured length, use a consistent Designation (or Wire Size + Ground Size if the job has no naming scheme) so the right runs get grouped onto the same reels, and fill in Start/End Location if you want per-end termination allowances calculated automatically instead of assumed.

Any takeoff export, any column order, any job. Headers are matched by meaning, not spelling, and columns it doesn't recognize ride along to the pull sheet untouched. Nothing needs deleting first.

How to get this CSV out of Bluebeam
  1. Open the Markups List. It's the panel across the bottom of Revu. If it's hidden, use the Markups tab on the side, or Alt+L.
  2. Show the columns you want. Right-click any column header → Columns → Manage Columns. Only visible columns get exported, so turn on the ones that matter: your length or measurement column, Designation, Start Location, End Location, Wire Size, Ground Size, Voltage, Conduit Type, Conduit Size, Length Adjustment. Extra columns are harmless here — this tool ignores what it doesn't need — so when in doubt, leave them on.
  3. Filter down to the runs you want, if you only want part of the sheet. Grouping and sorting don't matter; this tool re-sorts anyway.
  4. Don't flatten the PDF first. Flattening strips the live markup data and the list comes out empty.
  5. Click Summary on the Markups List toolbar → CSV Summary.
  6. Pick All Pages (or just the current page), keep column headers on, choose where to save it, and click OK.
  7. Drop that file above.

If Summary only offers PDF: that's a Revu 21 Basics subscription limit — CSV, XML and Print need Core or Complete. Ask whoever manages your licenses.

Check your measurement precision in Revu before exporting. If lengths come across as whole feet when you wanted inches, that's set in the measurement properties, not here.

1 · Takeoff

Drop the branch CSV

What this does: turns a Bluebeam branch-circuit export into a run-by-run conduit schedule and a color-coded wire spool order, so nobody's hand-tracking which phase color and neutral each circuit needs. For accurate results: set Voltage on every run using Bluebeam's High Volt/Low Volt picker (it decides brown/orange/yellow vs black/red/blue), and enter Circuits using this notation — a bare number with no letter means no neutral is pulled for it (4); add a trailing N for a circuit with its own neutral (4N); wrap circuits that share one neutral in parentheses with a trailing N ((4,6)N); separate multiple circuits or groups in the same conduit with commas, e.g. 1N,(25,27)N — one circuit with its own neutral, plus two circuits sharing one.

Same Bluebeam CSV Summary workflow as One Line, just a different export. Same lenient parsing: any column order, any job, unrecognized columns ride along untouched.

How to get this CSV out of Bluebeam
  1. Open the Markups List. It's the panel across the bottom of Revu. If it's hidden, use the Markups tab on the side, or Alt+L.
  2. Show the columns you want. Right-click any column header → Columns → Manage Columns. Only visible columns get exported, so turn on the ones that matter here: your length or measurement column, Circuits, Voltage, Wire Size, Ground Size, Conduit Type, Conduit Size, and Start/End Location (or Layer, if that's where your panel names live). Extra columns are harmless — this tool ignores what it doesn't need.
  3. Filter down to the runs you want, if you only want part of the sheet. Grouping and sorting don't matter; this tool re-sorts anyway.
  4. Don't flatten the PDF first. Flattening strips the live markup data and the list comes out empty.
  5. Click Summary on the Markups List toolbar → CSV Summary.
  6. Pick All Pages (or just the current page), keep column headers on, choose where to save it, and click OK.
  7. Drop that file above.

If Summary only offers PDF: that's a Revu 21 Basics subscription limit — CSV, XML and Print need Core or Complete. Ask whoever manages your licenses.

Double-check the Circuits notation before exporting a big set — a stray character (a comma outside parentheses, a missing close-paren) just drops that circuit from the count rather than erroring loudly, so it's worth a spot-check on step 3 after loading.
